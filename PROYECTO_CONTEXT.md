# Contexto del Proyecto - Portfolio Personal

## Descripción General
Este proyecto es un **portafolio personal** desarrollado por Julio Cárdenas, un programador colombiano enfocado en mostrar sus habilidades técnicas y proyectos personales. El sitio está construido utilizando tecnologías web frontend estándar y está diseñado para ser responsive y altamente interactivo.

## Tecnologías Utilizadas
- **HTML5**: Estructura semántica del sitio
- **CSS3**: Estilos y diseño responsivo
- **JavaScript**: Funcionalidad interactiva y galerías de proyectos
- **Media Queries**: Diseño adaptable a diferentes dispositivos

### 1. Navegación

## Características Técnicas Destacadas

### Galerías de Proyectos Interactivas
- **Sistema de navegación múltiple**: Botones anterior/siguiente y puntos de navegación
- **Modal de imágenes ampliadas**: Visualización en tamaño completo con navegación
- **Galerías independientes**: Cada proyecto tiene su propia galería con control individual
- **Navegación con teclado**: Soporte para flechas y escape
- **Responsive design**: Adaptable a diferentes tamaños de pantalla

### Funcionalidades JavaScript
- **Menú responsive**: Alternancia entre vista desktop y mobile
- **Galerías dinámicas**: Control de múltiples proyectos simultáneamente
- **Modal de imágenes**: Visualización ampliada con controles
- **Navegación contextual**: Flechas y puntos activos según imagen actual
- **Eventos de teclado**: Atajos para navegación

### Diseño
- **Tipografía**: Google Fonts (Poppins)
- **Colores**: Paleta minimalista con enfoque en contenido
- **Layout**: Flexbox para maquetación
- **Transiciones**: Efectos suaves en enlaces y botones
- **Iconografía**: Imágenes personalizadas para cada sección
